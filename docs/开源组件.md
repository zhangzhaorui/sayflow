## 不使用

- librime-lua 等脚本插件；方案里的 lua 组件在打包时全部删除（`scripts/patch_schemas.py`），自查脚本检查；
- glog：编译 librime 时 `ENABLE_LOGGING=OFF`，不写任何日志；
- 外部插件加载：`ENABLE_EXTERNAL_PLUGINS=OFF`；
- Squirrel（鼠须管）的代码和它带的 Sparkle 自动更新。

## 如何复现

`scripts/build-librime.sh` 按上表的 tag / commit 下载源码编译；`scripts/prepare-rime-data.sh` 下载词库和模型，记录 commit 和 SHA-256 到 `vendor/rime-data/VERSIONS.txt`。
