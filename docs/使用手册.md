# SayFlow 输入法使用手册

适用：Apple 芯片 Mac，macOS 13 及以上。

## 安装（第一次）

1. 从 [GitHub Releases](https://github.com/zhangzhaorui/sayflow/releases) 下载最新的 `SayFlow-*-arm64.dmg`，双击打开。
2. 把窗口里的 **SayFlow** 拖到「输入法文件夹（把 SayFlow 拖到这里）」，按提示输入开机密码。
3. 打开「系统设置 → 键盘 → 输入法」，点「编辑…」→ 左下角「+」→「简体中文」→ 选 **SayFlow** →「添加」。列表里没有 SayFlow 的话，先注销重新登录一次。
4. 如果系统提示「无法打开」或切换后没有反应：到「系统设置 → 隐私与安全性」，在页面下方找到 SayFlow，点「仍要打开」，然后注销重新登录。

## 切换输入法

- `⌃ 空格`：在 SayFlow 和其他输入法之间切换。
- 菜单栏右上角的白底 **S** 图标就是 SayFlow。

## 打字

| 想做的事 | 怎么做 |
|---|---|
| 打字 | 直接打全拼，整句也可以，例如 `jintianxiawukaihui` |
| 简拼 | 只打声母，例如 `wsm` → 为什么 |
| 选词 | 空格选第一个，数字键 1–8 选对应的词 |
| 翻页 | `-` / `=` |
| 展开更多候选 | 打字时按 `↓`，展开 7×7；方向键选择，回车上屏，Esc 收起 |
| 中英文切换 | 单按一下 `Shift`，屏幕下方提示「中文 / 英文」 |
| 中文标点 | 中文状态下直接按，`Shift + /` → ？，`,` → ， |

## 换输入方案

点菜单栏的 **S** 图标 →「SayFlow 设置…」→「打字」→「输入方案」：

- 全拼（整句）（默认）
- 小鹤双拼 / 自然码双拼 / 微软双拼
- 五笔 86
- 五笔 86 + 拼音混输：五笔码和全拼可以混着打，不会拆的字直接打拼音，候选旁会显示五笔编码；纯五笔下也可以先按 `z` 再打拼音查字

同一页还可以：改成竖排候选、关闭「记住我常打的词」、清空词库。

## 语音输入和 AI 改写（可选）

这两个功能需要一个兼容 OpenAI API 的后端，默认关闭。需要的话：

1. 准备一个兼容 OpenAI API 的服务地址和 API Key。
2. 「SayFlow 设置…」→「语音与 AI」：打开需要的开关，粘贴令牌，点「保存」，显示「连接正常」即可。
3. 用法：
   - **语音输入**：在任何输入框里按住**右 Command** 说话，松开后文字出现在光标处。第一次会请求麦克风权限，点允许。
   - **AI 改写**：选中一段文字，按 `⌃⌥R`，按 1–4 选「更正式 / 更简洁 / 翻译成英文 / 翻译成中文」，看完结果按回车替换，Esc 取消。

## 隐私

- 打字全部在本机，不联网，不记录、不上传。
- 个人词频只存在自己电脑上，可随时清空。
- 只有你按住右 Command 说的话、你选中并点了改写的文字会发到你设置的网关；三个联网开关都关掉时，SayFlow 完全不联网。
- 密码框里 SayFlow 不工作。

## 更新

从 GitHub Releases 下载新的 DMG，同样拖到「输入法文件夹」覆盖（选「替换」），然后切换一次输入法；没生效就注销重新登录。用过语音的话，需要重新允许一次麦克风。

## 卸载

1. 「系统设置 → 键盘 → 输入法」里选中 SayFlow，点「−」。
2. 在「终端」运行：`sudo rm -rf "/Library/Input Methods/SayFlow.app"`

## 常见问题

| 现象 | 处理 |
|---|---|
| 打拼音只出英文、不出中文 | 设置 →「打字」看输入方案是不是选成了双拼或五笔 |
| 菜单栏图标没变、列表里找不到 SayFlow | 注销重新登录一次 |
| `⌃ 空格` 切不过去 | 「系统设置 → 键盘 → 键盘快捷键 → 输入法」确认已勾选「选择上一个输入法」 |
| 语音没反应 | 设置 →「语音与 AI」确认语音已打开、令牌已保存、麦克风已授权 |
| 其他问题 | 到 GitHub 提 Issue |
